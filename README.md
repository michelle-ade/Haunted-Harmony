# Haunted Harmony 👻🎵

*A short & spooky musical game built in Unreal Engine 5*

This repository contains the Unreal Engine project files for **Haunted Harmony**, a 3D single-player game I developed as part of a *Game and Animation Production Workshop* module. This project explores interactive audio layering, modular environment design, and entirely custom assets.

---

## Project Overview 🛠 

In **Haunted Harmony**, the player controls the conductor ghost, navigating a haunted mansion to find and assemble the members of a ghost band. Each ghost joins the stage once their associated item is found, progressively layering instruments into the background music. The gameplay loop is simple, but the focus of the project was on the full production pipeline and technical execution.

**Note**: This repo does not contain a packaged build of the game — it's intended as a reference or portfolio project for learning and development purposes.

---

## Tools Used 🔧

Unreal Engine 5.3 - Game Development, Blueprint Logic
Blender - 3D Character, Object & Environment Modelling
BandLab - Music Composition
Krita - Textures, 2D Decals

This project served as a comprehensive introduction to the full production process, from visual development and prototyping to asset design and technical implementations.
